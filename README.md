# kaogong.skill · 考公选岗

> 「限制条件是对竞争者的物理截断，多维度叠加产生乘法效应。」——公考选岗第一定律

一个为 AI Agent 打造的**公务员岗位选择决策框架**（国考 / 京考 / 北京事业编，在职视角）。

基于 2026 年度官方公告（国家公务员局、北京组工、北京人社局）与主流公考机构方法论的多源深度调研，把「选岗」这件高信息密度、高容错率要求的事，变成一套**可复用、可验证、不依赖猜**的决策流程。

## ✨ 它能帮你做什么

- **筛岗**：把「可报岗」→「值得报岗」→「冲稳保梯度」一步步筛出来
- **判资格**：一票否决先行（公务员/参公禁报、京户限制、服务期、证书是否已到手）
- **解读职位表**：看清专业四层匹配、备注栏里的门槛 / 机会 / 坑
- **估难度**：用竞争比与近 3 年进面分评估上岸概率（区分 200 分制 / 100 分制卷）
- **定节奏**：报名时点博弈（中期报名、过审即锁定、避免最后一天）
- **守红线**：在职身份报考的资格程序、同意报考证明、政审「三龄两历」
- **给备选**：输出 1 冲 + 2 稳 + 1 保，附推荐理由、风险点与报名建议

内置 **5 大决策框架**（限制条件乘法漏斗、专业四层金字塔、身份红利套利、地域-层级-系统择低、备注栏情报学）、**10 条决策启发式**、**6 组流派分歧**（不搞一刀切）与完整的**北京决策地图**（京考 vs 国考北京 vs 北京事业编）。

## ⚠️ 定位与边界

- 本 Skill 提供**决策框架与筛选流程**，**不查询实时报名数据**（实时数据以当年官方《职位表》《报考指南》及报名系统为准）
- 政策逐年调整，**所有结论以当年官方公告原文为最终依据**
- 调研截止：2026-10-12，此后政策变化未覆盖

## 📦 安装

基于开放的 [Agent Skills 协议](https://agentskills.io)，兼容 Claude Code、opencode、Codex、Cursor、Gemini CLI 等支持 Skill 的 AI 工具。

**方式一：命令行安装（推荐）**

```bash
npx skills add stFloat/kaogong.skill
```

**方式二：手动复制**

| 工具 | 目录 |
|---|---|
| Claude Code | `~/.claude/skills/kaogong.skill/` |
| opencode | `.opencode/skills/kaogong/` 或 `~/.config/opencode/skills/` |
| Codex | `~/.codex/skills/kaogong.skill/` |
| 其他 | 参照各自的 Skills 文档 |

> ⚠️ 注意：Skill 名称与目录名保持一致（`kaogong`），否则可能无法加载。

Windows（PowerShell）示例：

```powershell
git clone https://github.com/stFloat/kaogong.skill.git
Copy-Item -Recurse .\kaogong.skill "$env:USERPROFILE\.claude\skills\kaogong.skill"
```

装好后**重启会话**，聊到选岗相关话题即会自动触发，也可直接提技能名或「帮我选岗」调用。

## 🚀 快速开始

直接告诉 AI 你的情况即可：

> 我在北京私企工作 4 年（计算机科学与技术，本科学历，无北京户口），想考公务员，帮我看看能报什么岗位、怎么选。

AI 会按「资格过滤 → 岗位分层 → 限制红利打分 → 竞争与进面评估 → 备注扫描 → 冲稳保输出」的 6 步流程给出建议。

### 职位表批量筛选脚本（可选）

仓库附带零依赖的筛选脚本，可对导出为 CSV 的官方职位表做硬条件批量过滤：

```bash
python scripts/filter_positions.py 职位表.csv --专业 "计算机" --学历 "本科" --备注排除 "五年服务期;二次分配"
```

详情见 [使用教程](docs/使用教程.md)。
