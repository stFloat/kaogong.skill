# 考公选岗 Skill 使用教程

本教程手把手教你安装和使用 `kaogong.skill`，包括 AI 对话选岗和职位表批量筛选脚本两部分。

---

## 1. 什么是 Agent Skill？

Skill 是一套「指令 + 脚本 + 参考资料」的文件夹，AI 工具可以在你提问时**按需加载**它，从而在特定领域表现得像专家一样稳定。本 Skill 就是把公考选岗的方法论打包成了这样一份「操作手册」。

它不需要联网也能提供框架判断；涉及最新招录政策、实时报名人数时，会引导你以官方数据为准。

---

## 2. 安装到你的 AI 工具

### 2.1 opencode（本 Skill 的默认环境）

把整个 `kaogong` 目录放进项目技能目录，或全局技能目录：

```powershell
# 项目级（跟随仓库，推荐团队共享）
Copy-Item -Recurse .\kaogong.skill .\你的项目\.opencode\skills\kaogong\

# 全局（所有项目可用）
Copy-Item -Recurse .\kaogong.skill "$env:USERPROFILE\.config\opencode\skills\kaogong\"
```

之后**重启 opencode 会话**。

### 2.2 Claude Code

```powershell
Copy-Item -Recurse .\kaogong.skill "$env:USERPROFILE\.claude\skills\kaogong.skill\"
```

重启会话即可。

### 2.3 Codex / Cursor 等其他支持 Agent Skills 的工具

参照各自官方文档，放入对应的 skills 目录（通常是 `.codex/skills/`、`.cursor/skills/` 或命令安装）。

> ⚠️ 关键：目录名必须为 `kaogong`（与 SKILL.md 的 `name` 字段一致），否则可能加载失败。

## 3. 用对话方式选岗

安装后，直接用自然语言描述你的情况即可，**无需特定口令**。

### 3.1 第一步：尽量说全自己的条件

AI 会主动追问缺失信息，但先说全能减少来回。推荐提供：

- 学历、学位、**专业全称**（如「计算机科学与技术」而不是「计算机」）
- 政治面貌（党员 / 预备党员 / 群众）
- 身份：应届 / 在职 / 事业编 / 公务员
- 在职者补充：是否在服务期、有无北京户口、基层工作经历几年
- 可用证书：四六级 / 法考 A 证 / CPA / 计算机等级
- 硬性红线：能否接受 5 年服务期、乡镇、夜班、二次分配

### 3.2 示例提问

```
我在北京私企工作4年（计算机科学与技术，本科，无北京户口，不是党员），
想考2026年的公务员或事业编，帮我看看能报什么、怎么选。
```

预期回答结构：
1. 资格过滤结论（能报 / 不能报，卡在哪）——本例会提示：京考社会岗需要北京户口、无京户在职者以国考北京职位为主战场
2. 可报岗位类型与专业分层结果
3. 限制红利评分
4. 冲稳保建议 + 报名时点

### 3.3 常用问题速查

| 你想问 | 这样说 |
|---|---|
| 岗位能不能报 | 「这个岗位（粘贴职位要求）我能报吗？」 |
| 不知道该报哪类考试 | 「国考、京考、事业编我该选哪个？」 |
| 解读备注 | 「帮我看下这个岗位备注里的『二次分配』是什么意思」 |
| 报岗时机 | 「报名第几天报比较好？」 |
| 三不限是否值得 | 「只有三不限能报，值得赌吗？」 |
| 在职身份合法性 | 「我事业编服务期没满，能考公吗？」 |

## 4. 职位表批量筛选脚本

适合已经下载了官方《职位表》Excel，想自己快速筛一轮的用户。

### 4.1 准备工作

1. 从官方渠道下载职位表（如国家公务员局专题网站）
2. 在 Excel 中另存为 **CSV（UTF-8）**：`文件 → 另存为 → CSV UTF-8（逗号分隔）`
3. 脚本只依赖 Python 标准库，**不需要安装任何第三方包**

### 4.2 基本用法

```bash
python scripts/filter_positions.py 职位表.csv --专业 "计算机" --学历 "本科"
```

- 组合条件为 **AND**（同时满足）
- 匹配方式为**模糊包含**（不区分大小写、忽略空格）
- 结果打印到屏幕，同时写入 `filter_result.csv`

### 4.3 支持的过滤项

| 参数 | 匹配列（自动识别别名） | 示例 |
|---|---|---|
| `--专业` | 专业 / 专业要求 / 专业名称 | `--专业 "计算机类"` |
| `--学历` | 学历 / 学历要求 | `--学历 "本科"` |
| `--学位` | 学位 / 学位要求 | `--学位 "学士"` |
| `--政治面貌` | 政治面貌 | `--政治面貌 "中共党员"` |
| `--基层` | 基层工作最低年限 / 基层工作经历 | `--基层 "2年"` |
| `--基层服务项目` | 服务基层项目工作经历 | `--基层服务项目 "三支一扶"` |
| `--户籍` | 户籍要求 | `--户籍 "北京"` |
| `--应届` | 应届相关列 | `--应届 "2026届"` |
| `--招录` | 招考人数 / 招录人数 | `--招录 "2以上"`（找招 2 人及以上的岗位） |
| `--备注` | 备注 | 一般配合排除使用 |
| `--备注排除` | 备注 | `--备注排除 "最低服务年限5年;二次分配;适合男性"` |

### 4.4 实战示例

**筛选：本科可报、专业相关、无 5 年服务期、非二次分配、不值守夜班的岗位**

```bash
python scripts/filter_positions.py 国考职位表.csv --专业 "计算机" --学历 "本科" --备注排除 "最低服务年限5年;二次分配;适合男性;需值夜班"
```

输出示例：

```
表头列：部门代码, 部门名称, 招录人数, 专业, 学历, ...
原始岗位数：20000  筛选命中：38

101 | 某省税务局 | 2 | 计算机科学与技术 | 本科 | ...
```

然后把这 38 个岗位交给 AI 做「冲稳保」排序即可。

### 4.5 常见问题

- **中文显示乱码？** 确认 CSV 另存为 UTF-8 编码；脚本会自动兼容 UTF-8 / GBK / UTF-8-BOM。
- **有些列没匹配上？** 脚本会打印「未识别到列」的警告，你可以把表头粘贴给 AI 让它帮你写一个自定义版本。
- **筛选太粗？** 模糊包含是故意设计的，先粗筛再精读，比直接漏报更安全。

## 5. 常见问题 FAQ

**Q1：安装后没生效？**
A：多数是目录名与 `name` 不一致或没重启会话。确认目录名为 `kaogong`，重启后输入「考公选岗」测试。

**Q2：Skill 会联网查报名人数吗？**
A：不会。它只做方法论判断与流程引导；实时报名人数、进面分数线请查官方报名系统与公务员局公示。

**Q3：政策是不是过时了？**
A：本 Skill 基线是 2026 年度公告（调研截止 2026-10-12）。每年公告发布后请以最新《招考公告》《报考指南》为准，必要时提示更新即可。

**Q4：我是应届生，还能用吗？**
A：可以。Skill 以在职视角为主，但对话中会先确认你的生源 / 择业期状态再给推断，结论请以当年公告复核。

**Q5：有没有操作风险？**
A：Skill 会帮你识别在职身份红线（如在职公务员禁报、同意报考证明时机、伪造材料的法律后果），请务必如实填报、绝不伪造证明材料。
